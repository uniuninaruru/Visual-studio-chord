## 0. 最重要の発見 — 現行エンジンに「転調」の概念が無い

### ★ 実曲データによる裏付け（ブログではなく一次データ）

[コード進行メモ倉庫](https://music-chord.com/)（JASRAC / NexTone 許諾済みの実曲コード進行DB）で**実際のアニメ主題歌2曲**を照合しました。

**① 幾田りら「百花繚乱」（『薬屋のひとりごと』第2期 OP）— 転調の塊**

| セクション | キー | コード |
|---|---|---|
| イントロ | **F** | Dm |
| A メロ | **A** | AonC♯ / Dm → G / F♯m / Faug / Em / A |
| B メロ | **A** | AonC♯ / Dm |
| サビ | **D** | G / A → F♯m / B → Em / F♯m → G / B♭ / C |
| **サビ2** | **E♭** | A♭ / B♭ / Gm / G♭dim7 → Fm / Gm / B / D♭ |
| C メロ | **D** | G / F♯m / B / Em / F♯m / G / A |
| アウトロ | **G♭** | E♭m → B / D♭ |

**1曲の中で F → A → D → E♭ → G♭ と転調**。しかも **サビ(D) → サビ2(E♭) は +1半音**＝まさにトラックドライバー転調。セクションごとに調も進行も違うという主張が、実データで確認できました。`Faug`（増三和音）、`G♭dim7`（減七の経過和音）、`AonC♯`（スラッシュコード）も実在。

**② milet「The Story of Us」（『葬送のフリーレン』第2期 ED）— 転調ゼロ**

D major を**最後まで維持**。最終サビも転調しません。セクション構成は  
A メロ `Dadd9–D/A–GM7–Gm7–D/A` ／ サビ `GM7–A–D/F♯–Bm7–GM7–A–D–D7` ／ C メロ `Em7–GM7–D–Bm7–Em7–GM7–Asus4–A`。

> **この2曲の対比が重要です。** 当初「転調はアニソンでほぼ義務的」と書きましたが、**それは誇張**でした。実際は **OP（アクション寄り）＝転調過多、ED（バラード）＝転調なし**という使い分けが見えます。エンジンには「転調は必須」ではなく**「転調の頻度・強度をスタイル/セクションで制御できるパラメータ」**として実装すべきです。
>
> なお ED の方も `Dadd9` `GM7` `Em9` `Gm7`（**同主短調からの借用 iv**）`D7` `Asus4` と、**三和音はほぼ使っていません**。7th/add9/9th が既定であるという指摘は両曲とも支持しています。

そして現行の `GeneratedComposition` は `settings.key` を1つしか持たず、**曲中で調が変わる仕組みが一切ありません**。

これは 9th/11th/13th の欠落より大きな構造的ギャップです。具体的に必要なもの:

| 転調の型 | 内容 | 該当ジャンル |
|---|---|---|
| **トラックドライバー転調**（最終サビ上げ） | 曲末で全体を **+1〜+2半音**上げる。ほぼ義務的な定番 | アニソン（確立）、アイドル、K-POP、電波、DECO*27 |
| **ピボットコード転調** | 共通和音を新しい調で読み替える。「気付きにくい」日本的な好み | アニソン |
| **直接転調** | 1小節の無音・ボーカルブレイク・上昇音で隠して直接跳ぶ | アニソン、電波 |
| **セクション間転調** | A→B→サビでそれぞれ調が違う | アニソン、K-POP（beat switch） |
| **異常転調** | 3度関係・トリトン関係など非隣接調へ跳ぶ | ももクロ/ヒャダイン系（学術論文が「わけのわからなさ」を研究対象にしている） |

**実装提案**: `GeneratedComposition` にセクション概念を導入し、各セクションが `key` と `progression` を持てるようにする。最小実装は「最終サビセクションを +2半音トランスポーズする」オプション（最も決定的で効果が大きい）。

なお Hello!Project のつんく♂ は逆に**安易な最終サビ半音上げを拒否**し、和声密度で盛り上げると指摘されています（転調の有無自体がスタイル差になる）。

## 1. 横断する共通言語 — 王道進行

**5ジャンル全てに現れる唯一の共通進行**であり、**唯一の学術的裏付けを持つ**進行です。

```
IV – V – iii – vi        （C major: F – G – Em – Am）
IVmaj7 – V7 – iii7 – vi7 （7th版。実際はこちらが標準）
```

- **学術的裏付け**: Maxwell Ramage, *Music Theory Spectrum* (2023) — 日本の歴代シングル売上トップ20の**約40%**、1989–2019年の年間1位曲の**23%**に出現
- 「小悪魔コード進行」（亀田誠治, 2014）とも呼ばれる。`V7→iii` の動きを「小悪魔的な恋人に心を折られる瞬間」と表現
- **主音 I に解決せず短調の vi に着地する**のが本質 → 現行 `CadenceType` では **`deceptive`** または **`loop`** に対応
- 解決版は循環に拡張: `IVM7–V7–iii7–vi–ii7–V7–I`（末尾が `authentic`）

**現行の `ChordQuality` で完全に表現可能**（major7 / dominant7 / minor7）。9th以上は不要。**最優先で進行テンプレートに追加すべき1件**です。

### 王道進行の親戚（同じく頻出）

| 名称 | 度数 | C例 | 備考 |
|---|---|---|---|
| 小室進行 | `vi–IV–V–I` | Am–F–G–C | 王道と逆に**I に解決**。高揚感。`authentic` |
| 丸サ進行 / Just the Two of Us | `IVmaj7–III7–vi7(–I7)` | FM7–E7–Am7(–C7) | `III7 = V7/vi` セカンダリードミナント |
| I–III–vi（アジア好み） | `I–III(=V/vi)–vi` | C–E–Am | 西洋ポップには稀な東アジア的動き |
| カノン進行 | `I–V–vi–iii–IV–I–IV–V` | | 下降ベース、スラッシュコード |
| VI–VII–i（ロック/アクション） | `VI–VII–i` | 短調 | 少年アニメOPの定番 |

## 2. アニソン（アニメ音楽）

### 2.1 セクションごとに違う進行を使う（重要）

日本の楽曲構成は業界用語で **Intro → A メロ → B メロ（前サビ）→ サビ → 間奏 → …→ D/C メロ → ラスサビ → outro**。

**各セクションは同じループを共有しません。** A メロ・B メロ・サビがそれぞれ別の進行を持ち、B メロは 8 小節程度で和声的にサビへ向けて登り詰めます（多くはドミナントか転調経由）。

現行エンジンは**1つの進行をループさせるだけ**なので、これは進行テンプレート選択と並ぶ大きなギャップです。

| セクション | 典型的な進行 |
|---|---|
| A メロ | 短調トニックのループ、または `I–III–vi` |
| B メロ（前サビ） | V へ向かって上昇するビルド |
| サビ | 王道 `IV–V–iii–vi` または小室 `vi–IV–V–I` |
| D/C メロ（ブリッジ） | 転調・借用和音 |
| ラスサビ | サビを **+2半音** |

### 2.2 その他の特徴

- **和声リズムが速い** — 1小節1〜2和音
- ロック＋オーケストラ＋J-POP のハイブリッド編成（和声自体は標準的、編成が派手）
- 借用和音・モーダルミクスチャー・セカンダリードミナントを「スパイス」として使う（`borrowed IV in minor`, `♭VI–♭VII–I`, `II7/III7/VI7`）

### 2.3 サブジャンル（※統合レベルの推測、学術的裏付けなし）

| サブジャンル | 傾向 |
|---|---|
| アイドルアニメ | 明るい、小室進行主体、最終+2半音転調 |
| 少年アクションOP | 短調、速い、`VI–VII–i` / `i–v–VI–VII`、♯dim経過和音、遠隔転調。サビで相対長調 `VI–VII–i–III` へ一時的に「勝利」 |
| 癒し系 / ED バラード | 遅い、maj7/add9、王道進行の哀感、`IV–I` プラガル終止 |

## 3. アイドル音楽（日本アイドル + K-POP）

### 3.1 日本アイドル

- **王道進行・カノン進行・小室進行の3本柱**。変種として `IVmaj7–V7–III7–vi`（iii7 を III7 = セカンダリードミナントに置換）、`ii(9)–V7–iii7–vi`
- **AKB48「恋するフォーチュンクッキー」** — Motown循環 + 王道 + カノンを1曲に同居。Verse: `I–vi7–IV–V`（循環）
- **つんく♂（Hello!Project）** — 「感情設計」。`III7→vi` のセカンダリードミナント、相対調転調（Cm → ♭VI–♭VII → 相対長調 E♭ → G7 で Cm へ回帰）、16ビートファンク
- **80年代歌謡アイドル**（松田聖子/筒美京平系）— `I–vi(–IV–V)` を核に city pop 的な色彩
- **電波アイドル**（でんぱ組.inc, MOSAIC.WAV系）— メロディとリズムが既にカオスなので**コードはあえて単純に保つ**（`I–V–vi–IV` か王道）。劇的な転調を**1曲1〜2回に配給**し、残りの色付けは借用和音で行う、という実践則
- **ももクロ/ヒャダイン系マキシマリズム** — 単一ループが存在しない。プログレ/メタル/テクノ/ミュージカル/オペラを1曲に詰め込み、**通常のJ-POPではありえない転調**。学術論文が「わけのわからなさ」を研究している

### 3.2 K-POP アイドル

- 骨格は西洋の Axis 系 4和音ループ（`I–V–vi–IV`, `vi–IV–I–V`）
- 色付けに maj7 / m7 / **m7♭5** / add9、R&B的な長短スライド（`Imaj7–iiim7–vim7–IVmaj7` に `♭VII`/`iv` 借用）
- **前サビでセカンダリードミナントによるリフト**（`V7/vi` = E7→Am、`V7/V` = D7→G）
- **最終サビのトラックドライバー転調**（+1〜+2半音）
- **beat switch** — セクションごとに独立したループ。遷移はカットかピボット/半音階転調

### 3.3 「メロディが和音を決める」（要検証）

アイドル/アニソンのメロディは**フック優先**で書かれ、6th・9th・導音といった色彩音に着地する。その結果**下の和音が richer になる**:

- メロディが IV上の9th → `IVadd9` / `IVmaj9`
- メロディが I上の6th → `I6`
- メロディが ♯4 → `V7/V` かリディアン色

**ボイシングコスト関数への示唆**: アイドル系プリセットでは、メロディ音を「その和音の使用可能なテンション」として配置することを、根音位置の単純さより優先すべき（**メロディが勝ち、和音が合わせる**）。ここが真の 9th/11th/13th が最も効く場所。

## 4. Kawaii future bass ★ ご指定のジャンル

### 4.1 ジャンル同定（確立）

future bass（Rustie/Hudson Mohawke が源流、Flume の 2013 Disclosure リミックスが雛形）の日本産派生。**Snail's House（Ujico*, 宇治家憲太郎, 2015 EP『Kirara』）が開祖**。周辺に Moe Shop, Yunomi, Synthion, Hyper Potions, Trifect。

親ジャンルの陰鬱で「brooding」な音色を、**明るく可愛くパステルな協和音**に置き換え、J-POP・アニメ・チップチューンと融合。Flume や San Holo より明確に**甘く、ダイアトニックに協和的**。

### 4.2 テンポと質感（確立）

- **140〜160 BPM で書き、ハーフタイムで感じる** — ドラムは 70〜80 BPM のヒップホップ/トラップ的グルーヴ（スネア/クラップが3拍目）、一方スーパーソウのコードとボーカルチョップは速いテンポで動く
  ※ melodigging の原文は「Aim for 140–160 BPM with a half-time feel」（**検証済み**）
- "Pixel Galaxy" は ChordU 計測で **149.75 BPM / C major**（検証済み）
- **和声リズムは遅い** — 1小節1和音、時に2拍1和音。厚いボイシングを響かせる余白が必要

### 4.3 現行 `ChordQuality` で綴れない和音（最重要）

シグネチャーは**デチューンされたスーパーソウの上に広く積まれた付加音**。

**検証で確認できた出典の実際の記述はここまで**:
- melodigging: 「Favor bright keys (major, Lydian) and **extended voicings (maj7, add9, sus2/4)**」
- UAL学生ブログ: 「**extended harmony such as 7ths and 9ths**」

> **訂正**: 当初この節には `BΔ7add9 – C6 – FΔ7add9 – Dm7add13` / `D6` / `G6` という具体的ボイシング例を記載していましたが、**両出典を直接開いた結果どちらにも存在せず**、削除しました。同様に `6/9`・`11th`・`13th` を出典が挙げているという記述も誤りでした（`7th` と `9th` までしか確認できない）。
>
> ただし **`major6`/`6-9`/`maj9` が現行 `ChordQuality` で綴れないという指摘自体は有効**です。理由は出典ではなく型定義の実地確認によります（下表）。7thと9thを同時に積めない制約は、出典が挙げる「7ths and 9ths」を満たすうえで実際に障害になります。

| 必要な和音 | 現行で綴れるか | 理由 |
|---|---|---|
| **major6 / 6-9**（1-3-5-6-9） | ❌ **不可** | `6` も `6/9` も品質として存在しない |
| **maj9**（1-3-5-7-9） | ❌ **不可** | `add9` は7thを含まず、`major7` は9thを含まない → **7thと9thを同時に積めない** |
| **dominant9 / minor9** | ❌ 不可 | `minorAdd9` は♭7を含まないので min9 とは別物 |
| **add11 / add13**（例 `Dm7add13`） | ❌ 不可 | — |
| maj7 / min7 / sus2 / sus4 / add9 | ✅ 可 | 平易なケースはカバー済み |

→ **`major6`, `6/9`, `major9`, `dominant9`, `minor9`, `add11/add13` が本ジャンル最優先の追加項目。** 特に「7thと9thを同時に積めない」という制約は、`baseQuality + tensions[]` 構造への移行を強く示唆します。

### 4.4 調性とモード

**圧倒的に長調**。「明るい調（major, Lydian）」と明記される出典あり。メロディは口ずさめる童謡的な短いモチーフ、順次進行、メジャーペンタトニック。短調は親ジャンルに比べ稀。

→ **Lydian（♯4/♯11）が現行 `Mode` の真のギャップ。** 現行は major/naturalMinor/harmonicMinor/dorian/mixolydian で、mixolydian（♭7）は求める明るさの代用にならず、dorian や短調系は完全に圏外。

### 4.5 進行

| 進行 | 度数 | 検証状況 |
|---|---|---|
| 王道進行（骨格） | `IVmaj7–V7–iii7–vi` | ✅ **確立**（Wikipedia/査読論文で数値まで一致） |
| ii から半音下降 | `ii –(半音下降)– V`（C: `Dm–C♯m–Cm–G`） | ⚠️ **UAL学生ブログ1件のみ**。同ブログは「genre-defining」と明言するが、melodigging には記載なし。**単一の弱い出典**として扱う |
| Snail's House "Pixel Galaxy" | ChordU: `C, F, Dm, B♭, B` / Hooktheory（間接）: `Fmaj7–E7–Am7–C7` | ⚠️ **出典間の不一致を実地確認**。C major・約150 BPM のみ両者一致。**進行は確定できない** |
| 明るいダイアトニックループを add9/maj7 で装飾（`I–V–vi–IV` 等） | — | ⚠️ **melodigging は進行例を一切載せていない**。当初の出典帰属は誤り。future bass 一般のチュートリアル由来として扱うべき |

> 注: `B♭` は C major では **♭VII（借用和音）**、`B` は非ダイアトニック。ChordU の解析が正しければ、この曲は素朴なダイアトニックループではなく**借用和音を含む**ことになります。どちらの解析も自動採譜/クラウドソース由来なので、確定には実音源の耳コピが必要です。

### 4.6 ボーカルチョップと声部進行

- **ピッチ付きボーカルチョップが和音構成音をなぞる** — Vocaloid や歌い手のボーカルを高くチューニング、フォルマントシフトで可愛い質感に。リズム的にキック/スネアと絡みつつ、**旋律的には和音構成音をトレースしてスーパーソウの和音を再ボイシングする**
  → メロディ生成を「現在の和音の構成音＋付加色彩音（9/6/♯11）」に制約すれば、決定的エンジンでも再現可能
- **声部進行**: チュートリアルが明示的に「共通音は同じ位置に保ち、跳躍より順次で動かす」と指示 → **現行のボイシングコスト関数（共通音保持＋最小移動）と1対1で対応**
  → ただし**色彩音（9th/6th/♯11）を上声に、根音を低く置く広い開離配置**へバイアスすべき（重み調整のみで実現可能、新規機構は不要）

### 4.7 プリセット設定の推奨

```
Mode         : major（理想は Lydian ＝現状は未実装）
Tempo        : 150–160 BPM（ハーフタイムのバックビート）
CadenceType  : loop（4小節シームレス反復）と deceptive（V7→vi）中心
               authentic の強い終止は稀。plagal / half を柔らかさに時々
和声リズム    : 1小節1和音
ChordQuality : 各三和音を add9 / maj7 / 6 で「着色」して描画
               （I → Iadd9、IV → IVmaj7 のように）
```

## 4.5 作家研究 — 田中秀和（MONACA）

アニソン/アイドル分野で**和声の複雑さが突出して分析対象になっている作曲家**。アイマス、ラブライブ、プリパラ等を手がけ、「難解なコード進行であっても失われないポップさ」が評価軸になっています。実務者による分析記事が豊富なため、**ニッチジャンルの中で最も具体的な和声データが取れる対象**です。

### 4.5.1 ブラックアダーコード（分数aug / 田中aug / イキスギコード）★最重要

**現行エンジンに全く該当概念がありません。** 日本のポップスで「キメの和音」として頻用される、実装価値の高い和音です。

```
表記:  Vaug/♭II        （略号 @ ）
C majorでの実体: Gaug/D♭  →  C
構成音: G-B-D♯ の aug に、ベース D♭
```

**なぜドミナントとして機能するか** — 3つの半音解決を内包するため:

| 構成音 | → | 解決先 |
|---|---|---|
| B | → | C（主音） |
| D♯ | → | E（第3音） |
| D♭ | → | C（主音） |

**理論的位置づけ**:
- 構成音が**全音音階（whole-tone scale）と一致** → 全音音階は対称で不安定＝ドミナント性が非常に高い
- 増六の和音（イタリア/フランス/ドイツ六）の仲間として「**Japanese 6th**」と分類されることもある
- 解釈は「aug コードに、根音の減5度下をベースに置いた分数コード」

**実例**（分析記事が挙げるもの）:
- 槇原敬之「どんなときも」1:21
- サンボマスター「世界はそれを愛と呼ぶんだぜ」1:12
- 田中秀和「グッドラック ライラック」0:07

**エンジンへの実装**: `augmented` 品質は既存だが、**分数コード（指定ベース）の仕組みが無い**ため現状は表現不能。`ChordEvent` にベース音指定（スラッシュコード）を追加すれば `Vaug/♭II` として表現でき、`CadenceType: authentic` の強力な代替ドミナントとして使えます。

### 4.5.2 オーギュメントの多用（田中秀和の署名）

| 用法 | 実例 | 内容 |
|---|---|---|
| **クリシェ内の経過和音** | 「Star!!」（デレマス OP）`D – Daug – D6 – D7` | トップノートが5度から**半音ずつ上昇**。前編で挙げたクリシェの上行版 |
| **非機能的な平行移動** | 「PUNCH☆MIND☆HAPPINESS」`Faug – E♭aug – Faug – E♭aug` | 機能和声を離れ、**全音音階的**に aug を平行移動 |
| **aug のオンコード**（極めて稀） | 「灼熱スイッチ」サビ頭 1:05 `Gaug/F – Em7 – G7 – C` | ベースが **♭VII**（スケール外音）。田中本人の説明では「`III7(♭13)` の omit5・7 としての `IIIaug`」の再解釈 |

`Faug – E♭aug` のような**全音音階に基づく非機能的平行移動**は、現行のボイスリーディングコスト関数（共通音保持・最小移動）とは**設計思想が逆**です。スタイル別に「非機能的平行移動を許可する」フラグが必要になります。

### 4.5.3 転調技法

| 型 | 内容 | 実例 |
|---|---|---|
| **短3度上転調** | 「劇的な感情の変化」 | ヴァルヴレイヴ: F♯ → A |
| 半音上転調 | 最後の繰り返しの climax | — |
| 近親調転調 | 滑らかな接続 | — |
| **遠隔調転調** | 「聴き手の予想を裏切る展開」 | — |

**短3度上転調は前節の実曲データ（百花繚乱の F→A も短3度上）とも一致**しており、アニソンの転調として +1/+2半音と並ぶ定番と見てよさそうです。

### 4.5.4 借用和音

ヴァルヴレイヴ A メロ: `F♯M7 – G♯m7 – AM7 – B7sus4 – B7`（`AM7` が F♯ major 文脈での借用）
C major での定番: `♭VI–♭VII–I`（A♭–B♭–C）、`iv–V–I`（Fm–G–C）

## 4.6 作家研究 — じん（自然の敵P）

カゲロウプロジェクトの作家。田中秀和が**垂直方向の複雑さ**（和音そのものの色彩）で際立つのに対し、じんは**水平方向**——**ベースの順次進行**と**非ダイアトニックな♯vi**、そして**転調の連鎖**——で特徴づけられます。ボカロとギターロック双方の文脈を持つため、現行の `rock` プリセットとも接点があります。

### 4.6.1 実データ①「Worlders」（feat. 初音ミク）★実曲DB照合済み

[コード進行メモ倉庫](https://music-chord.com/) で確認。**Key C major、転調なし**。

| セクション | コード |
|---|---|
| イントロ | `C – F/C – C` |
| A メロ | `C – C7 – F – B♭` |
| A メロ2 | `C – C7 – F – B♭ – Am – G – F` |
| B メロ | `B♭ – Am – F – G – Dm – Em – B♭ – Gsus4 – G` |
| **サビ** | `C – F – **E** – **G♯dim7** – Am – F – Em – B♭ – G` |
| サビ2 | `C – F – E – G♯dim7 – Am – F – Em – Dm – G – C – F – E – Am – B♭` |
| 間奏 | `C – F/C – C` ／ `C – **C/B♭** – C` |

**C major における非ダイアトニック和音が3種類**、明確に現れます:

| 和音 | 度数 | 機能 |
|---|---|---|
| `C7` | `I7` | **V7/IV**（IV へのセカンダリードミナント）。A メロ冒頭の定番 |
| `E` | `III`（=**V/vi**） | 次の Am へ向かうセカンダリードミナント。前編「I–III–vi（アジア好み）」と同型 |
| `G♯dim7` | `♯Vdim7` | `E`（V/vi）と `Am`（vi）の間を埋める**経過減七**。うちやま作曲教室のパターン9と同じ技法 |
| `B♭` | `♭VII` | 同主短調/ミクソリディアンからの**借用**。ロック的 |
| `C/B♭` | — | `I` の上に ♭VII ベース＝**スラッシュコード** |

→ サビの `E – G♯dim7 – Am` は「**セカンダリードミナント＋経過減七で vi に着地**」という、教科書的だが強力な型。`♭VII`(B♭)の多用がギターロック的な色を与えています。

### 4.6.2 実データ②「カゲロウデイズ」★分析記事より

**ベースの順次進行が設計の中心**です。

| セクション | ベースの度数進行 |
|---|---|
| イントロ後半 | `i – v – vi – vii`（自然短音階）→ i への推進力 |
| A メロ | `i – v – vi – **♯vi**` の反復 |
| サビ | `i – vii – vi – v – iv – v – **♯vi** – v` |

**♯vi が唯一の緊張点**で、記事は「解決しない不完全燃焼」と表現。期待される `vii – i` の解決を避け、`♯vi – i` にすることで「浮いた」響きを作る、と分析されています。

**転調の連鎖**（じんの署名）:

| 箇所 | 転調 | 効果（記事の記述） |
|---|---|---|
| サビ | **長2度上の短調** | ♯系へ移り明快さ・コントラスト |
| C メロ | **長2度下の短調** | ♭系の転調で「浮遊感・柔らかさ」 |
| ラスサビ | **短3度上の短調** | 定番の劇的高揚ではなく「浮遊感」 |

**ラスサビが +1/+2半音ではなく短3度上**という点が重要です。田中秀和の短3度上転調（ヴァルヴレイヴ F♯→A）とも一致し、**短3度上転調は日本のアニソン/ボカロで +半音と並ぶ定番**と見てよさそうです。

**音階**: 「ニロ抜き音階」（2度と6度を抜いた5音音階）を短調で使用。記事は「日本人に馴染む、西洋的でない民族的な強さ」と説明。**現行 `Mode` にペンタトニック系が無い**ため、これも表現できません。

### 4.6.3 田中秀和との対比（実装への示唆）

| | 田中秀和 | じん |
|---|---|---|
| 複雑さの方向 | **垂直**（和音の色彩） | **水平**（ベースの線・転調の連鎖） |
| 署名的和音 | ブラックアダー `Vaug/♭II`、aug 多用 | `♯vi`、経過減七 `♯Vdim7`、`♭VII` |
| 転調 | 短3度上・遠隔調 | **長2度上→長2度下→短3度上**の連鎖 |
| エンジンへの要求 | **分数コード**・aug の非機能的平行移動 | **ベース線を主役にした進行生成**・ペンタトニック音階・転調の連鎖 |

じんの「ベースが順次進行で動き、その上に和音を乗せる」という発想は、現行エンジンの**和音先行→ボイシングでベースが決まる**設計とは順序が逆です。`voicingCost` にベース線の順次性を報酬として加えるか、あるいは**ベース線を先に生成して和音を当てる**モードが必要になります。

## 4.7 作家研究 — 中田ヤスタカ（capsule / Perfume / きゃりーぱみゅぱみゅ）

**これまで調べた中で最も定量的な資料が存在する作家**です。ある分析はPerfume **110曲**を「調性の逸脱」という観点で分類し、統計を出しています。田中秀和＝垂直、じん＝水平だとすれば、**中田ヤスタカは「調性そのものを揺らす」**方向で特徴づけられます。

### 4.7.1 調性の逸脱 — 110曲の統計分析

| 逸脱の型 | 該当率 |
|---|---|
| **リディアン / ドリアン的性質** | 36%（36曲） |
| フレーズ単位でのモード使用 | 27曲 |
| **非ダイアトニック和音のみで構成** | 25% |
| **単純な転調を超えた複調（ポリトナリティ）** | 12%（13曲） |

分析者の結論は「調性から逸脱しつつポップなのが本当にすごい」。**4曲に1曲が非ダイアトニック和音のみ、8曲に1曲が複調**という数字は、現行エンジンの「1つの調・1つのモードで生成する」前提と真っ向から衝突します。

### 4.7.2 複調（ポリトナリティ）★現行エンジンに概念なし

**メロディと伴奏で別の調/モードを同時に鳴らす**技法。

| 曲 | 内容 |
|---|---|
| **∞ループ** | メロディ `key=E♭` / ベース `key=D♭` |
| Kiss and Music | メロディ **C ドリアン** ／ 伴奏 **C フリジアン** |
| Clockwork | メロディ **D エオリアン** ／ 伴奏 **G エオリアン** |
| edge | メロディ **F ドリアン** ／ 伴奏 **F エオリアン**（key=F minor） |

現行の `GeneratedComposition` は `settings.mode` を**1つしか持たず**、メロディ生成とコード生成が同じスケールを共有する設計です。**メロディとハーモニーに別々のモード/キーを持たせる**構造が必要になります。

### 4.7.3 テンションの「核（kernel）」という発想

分析者は `IIIm9` の9thを **kernel=♯4 / shell=9th** と呼び分けています。同じ音でも**文脈によってリディアン的な♯4として機能するか、単なる9thとして機能するか**が変わる、という捉え方です。

| 曲 | 例 |
|---|---|
| Butterfly | `F♯m` に `g♯` |
| Dream Land | `IΔ` に kernel=♯4（＝リディアン） |
| Drive'n The Rain | 同じ進行で `Gm9/C` と `Gm7/C` を**テンション配置だけ変えて**反復 |

→ **同一進行をテンション配置の差だけで反復する**のは、現行エンジンの「バリエーション生成」に直接応用できる考え方です。

### 4.7.4 具体的な非ダイアトニック用法

| 曲 | 和音 | 度数 |
|---|---|---|
| マカロニ | `Aφ` | `♯IVφ`（♯IVハーフディミニッシュ） |
| マカロニ | `D♭7 → E♭Δ` | **`♭VII → I`** |
| Take me Take me | **`FΔ/G`** | 分数コード。「中田的な色」と明記 |
| I still love U | `E7` に `g♯` | 転調感を段階的に高める |

`FΔ/G`（=`IVΔ/V`）は**またもや分数コード**です。田中秀和のブラックアダー、じんの `C/B♭` に続き、**3人の作家全員でスラッシュコードが署名的技法**として現れました。分数コード対応の優先度をさらに上げるべき根拠になります。

### 4.7.5 その他の署名的技法

- **「しれっと転調」** — A メロに転調を忍ばせる。派手な最終サビ上げとは逆の、気付かせない転調
- **ヨナ抜き音階（四七抜き）をサビで使う** — じんの「ニロ抜き音階」と同じく**ペンタトニック系**。現行 `Mode` で表現不能
- **同一進行を別の調で反復** — Zero Gravity は `Cm7/F→Gm` を `key=F` と `key=A♭` の両方の文脈で使用。`C7 on -9th` を接続に使い**シームレスに転調**
- **予想を外す平行移動** — `II→III→IV→V` と行きそうなところを `II→III→V→VI` にする

### 4.7.6 3作家の比較（実装への示唆）

| | 田中秀和 | じん | 中田ヤスタカ |
|---|---|---|---|
| 複雑さの方向 | **垂直**（和音の色彩） | **水平**（ベース線・転調連鎖） | **調性そのものを揺らす** |
| 署名 | ブラックアダー `Vaug/♭II`、aug | `♯vi`、経過減七、`♭VII` | **複調**、リディアン/ドリアン、`♯IVφ` |
| 転調 | 短3度上・遠隔調 | 長2度上→下→短3度上の連鎖 | **しれっと転調**、同一進行の別調反復 |
| 音階 | — | **ニロ抜き**（ペンタ） | **ヨナ抜き**（ペンタ） |
| 共通 | **分数コード** `Gaug/F` | **分数コード** `C/B♭` | **分数コード** `FΔ/G` |

**3人全員に共通するのが分数コードとペンタトニック志向**（じん・中田）でした。日本のポップス作家を実装対象にするなら、この2つは避けて通れません。

## 4.8 ジャンル — Artcore（アートコア）

音ゲー／同人シーン発の日本産電子音楽ジャンル。既存の `game-music` プリセットと隣接しますが、和声的にはかなり異質です。

### 4.8.1 ジャンル同定

- 2002年 **felys（Onoken）** が原型。ジャンル名としての初出は 2004年 beatmania IIDX 10th style の **「Narcissus At Oasis」（Ryu☆）**
- 高速 drum and bass / hardcore techno に、**クラシック的なピアノ・ストリングス**と情感的なメロディを融合
- BEMANI / BMS を中心とした同人音楽シーンで独自に発展。広義の **J-core** の一部

### 4.8.2 和声・構造の特徴

| 項目 | 内容 |
|---|---|
| **BPM** | **160–185**（4/4）※原典確認済み |
| コード | **add9 / sus / maj7** などの拡張和音、**モーダルミクスチャー**、**映画的高揚のための転調** |
| **構造** | **通作形式（through-composed）** — `Intro → Exposition → Development/Break → Climax → Epilogue`。**単純な drop/return ではない** |
| 音色 | 疾走する breakbeat の上に**ピアノのアルペジオ**とストリングス |

> **原典の限界を明記**: melodigging のページは**具体的なコード進行やローマ数字を一切挙げていません**。上記は「add9/sus/maj7、モーダルミクスチャー、転調」という一般的記述までです。（この出典は kawaii future bass で誤引用が判明した経緯があるため、今回は原文を直接引用して確認しました）

### 4.8.3 エンジンへの示唆

**最大の特徴は「通作形式」です。** 現行エンジンは 4/8/16 小節のループ生成が前提で、`Intro → Exposition → Development → Climax → Epilogue` のような**物語的に展開して戻らない構造**を表現できません。これは 4.5〜4.7 で見た「セクション別進行」よりさらに踏み込んだ要求です。

また音ゲー楽曲一般の傾向として「**頻繁な転調と、C メロ・D メロを含む多数のセクションで展開を作り、内容が密でありながらコンパクトにまとめる**」という指摘があり、これも通作形式・セクション構造の要求と一致します。

BPM 160–185 は現行の想定範囲（40–240）に収まります。

## 5. Future funk / City pop / Vaporwave

### 5.1 City pop（70〜80年代日本 AOR）

- **アイデンティティそのものが「三和音の拡張」** — maj7/min7/dominant7 → 9th/11th/13th、さらにオルタードドミナント（7♭9, 7♯5/7alt）と sus 色彩
- `ii7–V7–Imaj7`（長調）/ `ii7♭5–V7–i`（短調）のジャズ的動きが背骨
- 丸サ進行 `IVmaj7–III7–vi(–I7)` がもう一つの主力
- **「Plastic Love」（竹内まりや, 1984）具体分析**: Verse = **`Gm9–C7♭9–Am7–Dm7`**（ループ）
  ✅ **検証済み** — 複数のコードサイトがこの4和音で一致。イントロは `B♭maj7–Gm9–E♭7–B♭maj7–Am7–D` からこのループへ入る
  ⚠️ ただし**調の解釈は出典間で割れる**（D minor とする説と F major とする説）。度数ラベル（`ii9–V7♭9–iii7–vi7`）は F major 前提の解釈であり、**アナリスト依存**。エンジンに入れる際は度数ではなく**実音程の関係**で持つのが安全
- セカンダリードミナント、クロマチックメディアント、半音階ベース進行（`Fm7 → E♭m7` の ♭6→5 下降など）
- 平行短調からの借用（`iv(min7)`, `♭VII7`, `♭VImaj7`）、Dorian の IV ドミナントvamp

### 5.2 Future funk

- **和声は city pop から丸ごと継承**（サンプリングするため）。テンポ 115〜130、French house 的フィルタリング＋サイドチェイン、city pop をチョップしてピッチアップ
- チュートリアル例（Fm中心）: `i – i7 – I7♯5` に `♭VIIsus2` の刺繍（D♯sus2 – Fm – Fm7 – F7♯5）

### 5.3 Vaporwave

- スロー/ピッチダウン/チョップドアンドスクリュード。テンポ 60〜90
- **重要**: 遅くすることで**和声機能そのものが変わる**。Macintosh Plus『Floral Shoppe』の事例 — 原曲サビは G で `ii9(Am9)–iii7(Bm7)…VI(F♯m)–IV(C)–V(D)` とトニック不在。完全4度下げると**同じ和音が D major として聴き直される**
- 「timbre-as-content」／プランダーフォニクスの枠組み（Adam Neely）

### 5.4 プリセット推奨

| プリセット | テンポ | 特徴 |
|---|---|---|
| city-pop | 95–115 | 王道 + ii-V-I ループ、濃密な maj7/9 パッド |
| future-funk | 115–130 | 同じ和音、短いループ、フィルタースイープ＋サイドチェイン |
| vaporwave | 60–90 | lo-fi に近い、深いリバーブ、解決しない拡張ループ |

`CadenceType` は `loop` と `deceptive`（王道の V→iii→vi）優先。ii-V-I ターンアラウンドは `authentic`（ii 前置）。
**ボイシングコスト関数に「半音下降ベースへの誘因」を追加**すると丸サ/city pop 的な動きを捉えられる。

## 6. 電波ソング / ボカロ / 同人

### 6.1 電波ソング

- 和声基盤は**意図的に単純だがキラキラ** — `I–V/V–V`、`I–VI7–ii–V`（セカンダリードミナント混じりの長調ダイアトニック）
- **キーアップ転調と混沌とした調跳躍**が定義的所作。最終サビ前の半音/全音ギアシフト、時に連鎖
- 高速、四つ打ち、意図的な不協和

### 6.2 ボカロプロデューサーのジャズ的和声

| 技法 | 度数 | 信頼度 |
|---|---|---|
| 丸サループ | `IVmaj7–III7–vi7–I7`（C: FM7–E7–Am7–C7）※`III7=V7/vi`, `I7=V7/IV` | 確立 |
| 丸サ拡張（循環） | `IVmaj7–III7–vi7–v7–I7`（E♭: A♭M7–G7–Cm7–B♭m7–E♭7） | 広く流布 |
| セカンダリードミナント | `…III7–vi…` / `…VI7–ii…` / `ii/x–V7/x–x` ミニケーデンス | 確立 |
| **トライトーン代理（♭II7）** | `iim7–♭II7–Imaj7`（半音下降 D–D♭–C）、`♭VII7–I` バックドア | 確立 |
| モーダルインターチェンジ | `I–iv–I`（短調プラガル）、`I–♭VII–IV`、`I–♭III–♭VI`、`V–♭VI` | 確立 |
| Kanaria「KING」 | `i–♭III–♭VI–V`（Cm: Cm–E♭–A♭–G）※`♭VI→V` は**フリギア半終止**、和声的短音階のV | 広く流布 |
| DECO*27 | サビ `IV–III–vi–I`（E: A–G♯–C♯m–E）※III=V/vi | 広く流布 |

- **sasakure.UK** — チップチューン/ジャズフュージョン/プログレ、拍子と和声の激しい変化
- **Mitchie M** — 「リアル」ボカロ + city pop/ジャズファンクのリハーモナイズ、9th/13th拡張のii–V–I

### 6.3 同人 math rock / midwest emo（確立）

開放弦を活かした `add9`/`sus` ボイシングと声部進行。例: `Iadd9–IVsus2–vi(add9)–Vsus4` で **9thを共通音として保持**。調性が曖昧、4度堆積/sus色彩。

## 7. 実装優先順位（本調査からの結論）

前編の優先順位を、本調査の発見で更新します。

### 第1優先 — セクション構造 ＋ 転調機構（実曲データで確認）

現行に**存在しない**。ただし実曲2曲の照合で分かったのは「転調は必須」ではなく**「曲によって全く使う/全く使わない」**ということ（OP=転調過多、ED=転調ゼロ）。

したがって実装すべきは:
1. **セクション構造**（A メロ/B メロ/サビ/C メロが独立した進行を持つ）← **これが土台**。転調しない曲でもセクション別進行は必須（milet の例が実証）
2. **セクション単位の `key`** ← その上に載る任意機能
3. **転調の頻度・強度パラメータ** ← 「必須」ではなく**スタイル別に制御**。最小実装は「最終サビを +1〜+2半音」

### 第2優先 — 進行テンプレート選択 + 王道進行の投入

王道進行 `IVmaj7–V7–iii7–vi` は**学術的裏付けがあり、現行 `ChordQuality` で完全に表現でき、5ジャンル全てで使える**。最もROIが高い1件。

同時に `vi–IV–V–I`（小室）、`IVmaj7–III7–vi7`（丸サ）、`I–III–vi`、`VI–VII–i` を**エンジンのプリミティブとしてハードコード**する。個別曲の分析は「例示」に留め、ground truth として扱わない（誤ラベルの出典が多いため）。

### 第3優先 — セクション別進行

アニソン/K-POPは A/B/サビで別進行。現行の「1ループ反復」では本質的に再現不可。

### 第4優先 — `ChordQuality` 拡張（優先順位が明確化された）

1. **`major6` / `6-9`** — kawaii future bass の必須音（現状綴れない）
2. **`major9` / `dominant9` / `minor9`** — 「7thと9thを同時に積めない」制約の解消。`minorAdd9 ≠ minor9`
3. **オルタードドミナント `dominant7♭9` / `dominant7♯9` / `dominant7♯5`** — city pop（Plastic Love の `V7♭9`）、丸サ、トライトーン代理
4. **`dominant13` / `major13`** — AOR パッド
5. **`minor11` / `add11` / `add13`**

→ 列挙値を増やし続けるより **`baseQuality + tensions[]` 構造への移行**を検討すべき段階。

### 第5優先 — モード追加

**Lydian**（kawaii future bass の明るさ、♯11）、**Phrygian**（Kanaria の ♭II/♭VI–V）。

### 第5.5優先 — 分数コード（スラッシュコード）★新規発見

`ChordEvent` に**任意のベース音を指定する仕組みが無い**ため、以下がすべて表現できません:

- **ブラックアダーコード** `Vaug/♭II`（田中秀和・J-POP のキメ和音、4.5.1）
- **aug のオンコード** `Gaug/F`（灼熱スイッチ）
- **ゴスペルのトレイン進行** `C–C/B–Am–Am/G–F–F/E–Dm–G`（前編3章）
- **カノン進行の下降ベース** `C–Em7/B–Am–Am7/G`（うちやま作曲教室パターン5）
- 実曲データで確認された `AonC♯`（百花繚乱）、`D/A` `D/F♯`（milet）、`C/B♭` `F/C`（じん「Worlders」）
- **`FΔ/G`（中田ヤスタカ「Take me Take me」）** — 分析者が「中田的な色」と名指しする署名和音

現行の `inversion` は「和音構成音の転回」しか表せず、**構成音でないベース音**（`Vaug/♭II` の ♭II、`Gaug/F` の F、`FΔ/G` の G）は指定できません。

> **調べた作家3人（田中秀和・じん・中田ヤスタカ）全員で、分数コードが署名的技法として現れました。** 加えて実曲DB照合2曲でも高頻度。日本のポップスを対象にするなら**避けて通れない機能**と判断します。

### 第5.7優先 — ベース線主導の進行生成 ★新規発見（じん）

現行は **和音を決める → ボイシングでベースが従属的に決まる**という順序ですが、じんの楽曲は逆に**ベースの順次進行（`i–v–vi–♯vi`、`i–vii–vi–v–iv–v–♯vi–v`）が設計の中心**にあります。ゴスペルのトレイン進行やカノン進行の下降ベースも同じ構造です。

対応案は2つ:
1. `voicingCost` に**ベース線の順次性を報酬**として加える（軽量）
2. **ベース線を先に生成し、それに和音を当てる**生成モードを追加（本格的）

### 第5.8優先 — ペンタトニック音階 ★新規発見（じん・中田ヤスタカ）

- じん「カゲロウデイズ」= **ニロ抜き音階**（2度・6度を抜く）を短調で
- 中田ヤスタカ = **ヨナ抜き音階（四七抜き）** をサビで使うのが「得意技」

**2作家が独立にペンタトニックを署名技法にしている**点は重い。現行 `Mode` は7音音階のみで表現できません。和音は7音音階のまま、**メロディ生成側だけペンタトニックに制限する**設計が自然です（実際どちらも「サビのメロディで使う」技法）。

### 第5.9優先 — 複調（メロディとハーモニーで別のモード/キー）★新規発見（中田ヤスタカ）

Perfume 110曲中 **12%が単純な転調を超えた複調**（∞ループ: メロディ `key=E♭` / ベース `key=D♭`、Kiss and Music: メロディ C ドリアン / 伴奏 C フリジアン 等）。

現行は `settings.mode` が1つで、メロディ生成とコード生成が同一スケールを共有します。**メロディ側とハーモニー側に別々の `mode`（さらには `key`）を持たせる**だけで実現でき、構造変更としては比較的小さい割に効果が大きい項目です。

### 第5.95優先 — 通作形式（through-composed）★新規発見（artcore）

artcore は `Intro → Exposition → Development/Break → Climax → Epilogue` と**展開して戻らない**構造が本質。現行の 4/8/16 小節ループ生成では表現できません。第1優先の「セクション構造」をさらに進めて、**セクションが反復せず物語的に進行する**モードが要ります。

### 第6優先 — 機能的役割の配置

`♭II7`（トライトーン代理）、`V7/x`（セカンダリードミナントの任意度数配置）、借用和音の平行モード置換。品質自体は既にあるが、**その度数に置ける機能的役割**が無い。

### 第7優先 — ボイシングの重み調整

- kawaii future bass: 色彩音を上声、根音を低く、**広い開離配置**
- city pop / 丸サ: **半音下降ベースへの誘因**
- アイドル: **メロディ音を和音の使用可能テンションとして配置することを優先**（メロディが勝つ）
